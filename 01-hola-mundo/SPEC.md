# Spec — Módulo 01 · Hola, mundo (proyecto para hacer solo)

## Objetivo
Mostrar **nombre + legajo + stack** en un componente, entendiendo `createRoot`, `render` y qué es un componente.

## Requisitos
- **R1** — `App` muestra nombre y legajo en un `<h1>`.
- **R2** — Un `<p>` con el stack que estás aprendiendo (React + TypeScript + Vite).
- **R3** — `<main>` como contenedor raíz (HTML semántico).

## Fuera de alcance
- Props, estado, rutas (→ módulos siguientes).

## Criterios de aceptación
- [ ] `pnpm dev` levanta en `localhost:5173`.
- [ ] Veo nombre + legajo.
- [ ] Usé `<main>` (no un `<div>`).
- [ ] Entendí que un componente es una función que devuelve JSX/TSX.
